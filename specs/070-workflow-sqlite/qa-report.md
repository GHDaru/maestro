Confirmed by reading the code and by the red test (`no such table: rodadas` after the second ingest). Fixed in `04e559c`. This is the strongest argument the reviewer raised against ADR 0025 as built; it is now condition 3 of the ADR.

Plan, tasks and this file now say so, and Principle IV is marked ⚠️ in the Constitution Check — a retroactive cycle integrates what exists and names what is missing; it does not re-implement the branch.
- **Append-only is a word, not a trigger.** Found while choosing the mutations, confirmed by the review and the security pass (`schema_workflow.sql` has no trigger; the Stop hook updates rows). Plan, tasks and ADR 0025 corrected before `5d122ec`; after the review `DOM:invariants` was tried as `none`, the gate rejected the value, and it stays `edge` with the reason rewritten (the only enforced invariant lives in the ingest adapter).
- **Mutation (c) was coarser than designed.** Removing one column line broke the SQL, so all seven schema tests failed instead of the one column assertion. Reported as observed.
- **Test counts in the plan were written before measuring.** The first draft said 10 and 7 for `test_fr13_fr14.py` and `test_workflow_painel.py`; the runs say 9 and 8. Corrected from the output.
