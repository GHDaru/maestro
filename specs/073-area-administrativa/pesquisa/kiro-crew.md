- **O que foi aberto de verdade**:
  - https://kiro.dev/ — o FAQ descreve Kiro como "an agentic AI with an IDE, CLI, web interface, mobile app, and Kiro Crew"; fala de "parallel agents that learn from every session", preço "credit-based" e padrões abertos "Agent Client Protocol (ACP)", AGENTS.md, "Skills.md", MCP.
  - https://kiro.dev/docs/ — índice da documentação: seções de Sub-agents, Crew, Cloud sessions, Memory, Models, MCP e Enterprise (governance, IAM, monitor-and-track, billing).
  - https://kiro.dev/docs/crew/ — "Kiro Crew" é descrito como "an open-source personal AI agent that runs locally or remotely on your hardware", "persistent, self-learning, and self-evolving"; cada aba é "an independent session"; há Projects, Task Runner, Schedule e Heartbeats; pode "spawn isolated subagents".
  - https://kiro.dev/docs/crew/features/ — lista Subagents, Scheduling, Artifacts, Agent backends (Preview), Multi-instance, Task Runner, Memory, Knowledge, Snapshot & restore, Browser, Computer Use, Workflows.
  - https://kiro.dev/docs/crew/security/ — "Owner lock", "Secrets vault" ("Encrypted at rest", "Masked in the UI"), "Denied commands", "Governance ceiling", "OS sandbox", níveis de aprovação e "security event log".
  - https://kiro.dev/docs/crew/chat/ — chat é "the primary way you work with Kiro Crew"; cada aba é sessão independente; página "/sessions" é inventário; Side Chat lê "a frozen snapshot of the parent context". A página não descreve caixa de entrada.
  - https://kiro.dev/docs/crew/apps/ — "The App Kit is what turns Crew into a platform"; apps contribuem agentes, skills, MCP servers, cron jobs, UI; mensagens de app empurradas para o chat ("text-only, limited to 16,384 characters"); apps só iniciam/guiam/param sessões se autorizado.
  - https://kiro.dev/docs/crew/configuration/ — config em `config.json`/`config.local.json`; painéis Settings (Secrets, Skills, Messaging Channels, Security); Agent Harness; Selectable Models; `agent.sandbox` (auto/strict/off); chaves `KIROCREW_HOME`/`KIROCREW_PORT`.
  - https://kiro.dev/docs/custom-agents/ — agente custom é definido por arquivo em `.kiro/agents/[name].json`|`.md` (projeto) ou `~/.kiro/agents/` (global), com `tools`, `excludedTools`, `resources`, `permissions` (`{ "capability": "shell", "match": [...], "effect": "allow" }`), `model`.
  - https://kiro.dev/docs/custom-agents/subagents/ — sub-agentes rodam "in their own isolated context"; `toolsSettings.subagent` com `availableAgents` e `trustedAgents`; "Task graphs are planned upfront and cannot be modified during execution"; built-ins "Context gathering" e "General purpose"; nomes desconhecidos falham ("verify with `kiro-cli agent list`").
  - https://kiro.dev/docs/memory/ — memória é "a record with a title, description, and content, not a copy of a past conversation"; "stored locally per user account, not per workspace".
  - https://kiro.dev/docs/cloud-sessions/ — sessão "runs the Kiro agent harness in a managed cloud sandbox instead of on your machine"; estado sobrevive; reconexão via `kiro-cli --resume-id <session-id>`; "Delete Session" remove sessão e sandbox; "up to 10 concurrent cloud sessions"; nenhum pause/stop documentado.
  - https://kiro.dev/docs/mcp/ — MCP "extends Kiro's capabilities"; suporta "Local (stdio)" e "Remote (HTTP/SSE)" servers, config JSON sob `"mcpServers"`; prompts/recursos servidos.
  - https://kiro.dev/docs/acp/ — o Agent Client Protocol "connects an editor, application, or custom integration to the Kiro agent"; ACP = "How does a user interact with and control the agent?", MCP = "Which additional systems can the agent use?".
  - https://kiro.dev/docs/hooks/ — hooks "run shell commands or agent prompts automatically when specific events happen"; triggers `PreToolUse`/`PostToolUse`/`Stop` "gate dangerous operations".
  - https://kiro.dev/docs/models/ — catálogo de modelos (Claude, GPT-5.6 Sol/Terra/Luna, etc.); dropdown no chat; roteamento por geografia/global; "reasoning effort" controlável.
  - https://kiro.dev/docs/billing/ — tiers Free/Pro/Pro+/Pro Max/Power (50–10.000 créditos); add-on credits; "your usage cap renews at the beginning of the next billing cycle".
  - https://kiro.dev/pricing/ — preços por usuário/mês; créditos; overages "$0.04 per credit", "Overages are disabled by default and must be enabled in the Kiro console settings"; Free "subject to rate limits".
  - https://kiro.dev/docs/enterprise/governance/ — controles em "Settings > Shared settings": model access management, MCP allow-list/registry, API keys, web tools, sign-in controls, toggle de Cloud Sessions.
  - https://kiro.dev/docs/enterprise/iam/ — autorização do console via AWS IAM (políticas JSON); condition keys `identitystore:RequestUserArn`/`RequestGroupArn`; service-linked roles.
  - https://kiro.dev/docs/enterprise/monitor-and-track/ — Dashboard de "aggregate user activity metrics", "User activity reports", "Prompt logs", AWS CloudTrail/CloudWatch, export CSV de assinaturas.

## Observações
- **"Crew" existe e tem esse nome**: "Kiro Crew" é um workspace/agente pessoal open-source que roda na máquina ou remoto. Não é, porém, um recurso de "times/agentes em paralelo por time" no sentido de equipes — o paralelismo vem de "Subagents" e de "Multi-instance" (várias instâncias Crew em um hub). O gerenciamento multiagente está em `/docs/custom-agents/subagents/`.
- **Pago**: quase tudo de governança/administração é Enterprise (quote-based) ou tiers pagos (Pro $20 → Power $200). Créditos e overages são cobrados; o Free é limitado por créditos e "subject to rate limits".
- **Lacunas**: não achei documentação de "filas e workers" nem de "livro de mensagens"; a caixa de entrada **não é documentada** (busca vazia → `—`, não `não`; o contato é por canais: Slack, Discord, Telegram, Teams, Webex, WeCom, WeChat). A2A **não** aparece em kiro.dev — os protocolos documentados são MCP e ACP.
- **Correção da rodada 4 (26/10)**: a célula *caixa de entrada* passou de `não` para `—` — a página diz que **não cobre** o inbox, o que é ausência de fonte, não ausência afirmada. As demais células `não` desta ficha (ex.: *pausar*) permanecem: a fonte **afirma** a ausência ("no pause/stop — only Delete Session").
- Tudo nesta ficha é documentação lida; **nada foi executado** localmente e nenhuma conta/credencial foi usada.
