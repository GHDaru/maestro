  - https://aws.amazon.com/bedrock/agentcore/ — "The platform for production AI agents. Any framework. Any model. Secure at scale."; fala de Gateway, Evaluations, Runtime e "access policies verified by automated reasoning".
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/what-is-bedrock-agentcore.html — tabela de serviços: Harness, Runtime, Memory, Gateway, Identity, Code Interpreter, Browser, Observability, Payments, Evaluations, Optimization, Policy, Registry; preço "consumption-based pricing".
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agents-tools-runtime.html — Runtime: "session isolation" (cada sessão em "a dedicated microVM"); protocolos MCP e A2A; sessões "up to 8 hours on microVMs, or up to 14 days on Instances"; "Built-in authentication" via Identity; observabilidade embutida; payload 100MB.
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway.html — Gateway: converte APIs/Lambda em ferramentas MCP; "passthrough targets" para A2A; "Semantic Tool Selection"; "Secure Credential Exchange"; "comprehensive ingress authentication and egress authentication".
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/gateway-fine-grained-access-control.html — access control em 4 níveis (gateway, tool, operation, parameter); JWT claims validation, IAM principal matching, external authorization services.
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/identity.html — AgentCore Identity: identidades como "workload identities"; inbound JWT authorizer; credential providers; integração com Cognito, Okta, Microsoft Entra ID, Auth0.
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory.html — Memory: "Short-term memory captures turn-by-turn interactions within a single session"; "Long-term memory automatically extracts and stores key insights from conversations across multiple sessions".
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/observability.html — Observability: dashboards via Amazon CloudWatch; métricas "session count, latency, duration, token usage, and error rates"; telemetria "OpenTelemetry (OTEL)-compatible"; trace visualizations.
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/policy.html — Policy: policies determinísticas em Cedar (e Dogwood); "intercepts all agent traffic through ... Gateways"; natural-language authoring; temporal policies ("requiring that an approval was granted before a transfer", "keeping a running total under a budget"); "Audit Logging".
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-sessions.html — sessões isoladas; estados "Active", "Idle", "Stopped"; "session storage" persiste filesystem entre stop/resume; headers por protocolo (`Mcp-Session-Id`, `X-Amzn-Bedrock-AgentCore-Runtime-Session-Id`).
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-a2a.html — deploy de servidores A2A (Agent-to-Agent); JSON-RPC; descoberta via "Agent Cards" em `/.well-known/agent-card.json`; autenticação SigV4/OAuth 2.0.
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-stop-session.html — `StopRuntimeSession` "instantly terminates the specified session and stops any ongoing streaming responses"; erro 429 em `ThrottlingException`.
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-lifecycle-settings.html — `LifecycleConfiguration`: `idleRuntimeSessionTimeout` (60–28800s microVM / 60–1209600s Instances, default 900s) e `maxLifetime` (default 28800s).
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/registry.html — AWS Agent Registry: catálogo para "publish MCP servers, tools, agents, agent skills, and custom resources"; workflow de aprovação; "hybrid search"; endpoint MCP nativo; autorização IAM ou JWT.
  - https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/payments.html — AgentCore payments: microtransações x402; "Each PaymentSession has a configurable budget limit (maxSpendAmount, currency) and an expiry time".

## Observações
- **Documentação apenas**: nada foi provisionado. Nenhum console AWS, credencial ou conta foi usada — os exemplos de código nas páginas usam placeholders (`123456789012`, `us-west-2`) e não foram executados. `docker` não existe nesta máquina e não é necessário.
- **Pago**: AgentCore é "consumption-based pricing with no upfront commitments or minimum fees"; Payments cobra por uso (x402) e há custo de CloudWatch/ECR/IdP. A página de pricing está em https://aws.amazon.com/bedrock/agentcore/pricing/ (não aberta).
- **Lacunas**: não achei "caixa de entrada" nem tratamento de "colisão de nomes". "Última atividade" e "consumo por modelo" não são explicitamente documentados. Vários recursos (Harness, Optimization, Evaluations) aparecem como serviços que **não** foram abertos em detalhe.
- Siglas expandidas na primeira ocorrência: AWS (*Amazon Web Services*); MCP (*Model Context Protocol*); A2A (*Agent-to-Agent*); RBAC (*Role-Based Access Control*); JWT (*JSON Web Token*); OTEL (*OpenTelemetry*); IdP (*Identity Provider*).
