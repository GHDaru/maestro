# Microsoft Copilot Studio

- **URL**: https://learn.microsoft.com/en-us/microsoft-copilot-studio/ (produto em https://copilotstudio.microsoft.com)
- **Data da visita**: 2026-10-24
- **Como foi pesquisada**: WebFetch na documentação oficial em learn.microsoft.com (nenhum binário local, nenhum login). Páginas: overview, publicação/canais, autenticação, ambientes, DLP (*Data Loss Prevention*), inventário de agentes, analytics, cotas, licenciamento, governança e segurança, logs de auditoria, MCP (*Model Context Protocol*), A2A (*Agent2Agent*) e "connected agents".
- **O que foi aberto de verdade**:
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/fundamentals-what-is-copilot-studio — Copilot Studio é "a graphical, low-code studio for building and managing AI-powered agents and workflows"; blocos: Agents, Workflows, Agent flows; harnesses (GitHub Copilot, Customer Conversation, standard); "**Administration**: inventory, secure, and manage agents across your organization, with role-based access and cost management"; workflows têm "human-in-the-loop controls".
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-agent-inventory — inventário centralizado "of all agents created using Copilot Studio or Agent Builder", cobre publicados e rascunhos; campos `displayName`, `createdAt`, `lastPublishedAt`, `channels`, `authentication`, `model`, `orchestration`, `isQuarantined` (preview), `sharedWithViewers/Editors`; acessível via Power Platform admin center, Power Platform API e Azure Resource Graph; "changes to an agent typically appear within 20 minutes".
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/security-and-governance — controles: DLP, environment routing, CMK (*Customer-Managed Keys*), "Usage visibility and Copilot credit governance" com "pay-as-you-go Copilot credit caps to manage spend", audit logs no Microsoft Purview e no Microsoft Sentinel, "Disable agent publishing"; Agent 365 como "central control plane".
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-overview — página **Monitor**: métricas de sessões conversacionais e de gatilho, usuários ativos (DAU/MAU), transcrições para download (últimos 28 dias), dados por tópico; sessão de conversa expira após 30 min de inatividade; share role *Analytics Viewer* + security role *Bot Transcript Viewer*.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-logging-copilot-studio — audit logs no Microsoft Purview: eventos administrativos (`BotCreate`, `BotDelete`, `BotUpdateOperation-BotPublish`, `BotShare`) e de uso (`CopilotInteraction`); campos `BotId`, `BotSchemaName`, `BotComponentId`; a coleta "can't be disabled" mas o log em Purview pode.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-data-loss-prevention — data policies no Power Platform admin center: grupos de dados (Business/Non-business/Blocked) e conexões que impedem publicar sem autenticação, usar conectores como ferramentas, HTTP, canais específicos, gatilhos de evento; "endpoint filtering" permite allow/deny de endpoints.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/requirements-quotas — cotas em requests per minute (RPM)/requests per hour (RPH): 8.000 RPM por ambiente (plano pago); cotas de mensagens generativas escalam com os prepaid packs (50 RPM/1.000 RPH a 100 RPM/2.000 RPH); limites: 1.000 tópicos/agente, 100 skills/agente, 500 knowledge sources.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/billing-licensing — Copilot Credits como moeda comum; pay-as-you-go, prepurchase plan e prepaid packs; "Copilot Studio enforces purchased capacity monthly, and unused Copilot Credits don't carry over"; enforcement pode levar a "service denial".
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/requirements-licensing — licença por usuário + licença de tenant; "The consumption of the capacity isn't reported at the tenant level, but can be seen for each individual agent".
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-fundamentals-publish-channels — publicar "updates on all connected channels"; canais (Teams/Microsoft Copilot, SharePoint, WhatsApp, Facebook, Azure Bot Service, web); sessão muda após novo início; admins controlam canais ("Agent access channels").
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/configuration-end-user-authentication — opções: No authentication, "Authenticate with Microsoft" (Entra ID) e "Authenticate manually" (Entra ID v2 com client secrets/certificates/federated, ou Generic OAuth 2); campos incluem Client secret e "Client Certificate KeyVault URL"; *Require users to sign in*.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/environments-first-run-experience — "An environment is a space to store, manage, and share your organization's business data"; environment routing; operações de ciclo de vida (backup/restore, delete, recover, copy, reset; move não suportado).
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-share-bots — compartilhamento para chat (usuários, grupos de segurança, toda a organização) e para coautoria; papéis de compartilhamento *Analytics Viewer* e *Agent Viewer*; "Copilot Studio detects a conflict" em edição simultânea de tópico (oferece Discard changes / Save copy); security roles Dataverse (*Environment Maker*, *Bot Transcript Viewer*).
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-create-edit-topics — tópicos (sistema vs. custom), nós (Message, Question, Condition, Tool, etc.), orquestração generativa vs. clássica, code editor (YAML).
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/agent-extend-action-mcp — "You can extend your agent with tools by using Model Context Protocol (MCP)"; MCP tools e resources; exige orquestração generativa; conectar a servidor MCP externo ou criar novo; publicar conector MCP entre tenants.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/add-agent-agent-to-agent — "Agent2Agent (A2A) protocol is an open standard for communication and collaboration between agents"; adicionar "A2A agent" por endpoint URL, autenticação None / API key / OAuth 2.0; puxa nome/descrição do *agent card* em `/.well-known/agent.json`; payload com `contextId`, historico de chat.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/authoring-add-other-agents — "Connected agents are agents your primary agent can invoke during a conversation"; conecta agentes do Copilot Studio, do Microsoft Foundry, remotos via A2A e do Microsoft 365 Agents SDK; "the primary agent delegates the request"; limitação de tamanho do payload de handoff.

## Observações
- **Versão livre vs. paga**: o acesso ao produto é por licença; há *Copilot Studio User License* (gratuita) que exige um prepaid pack de tenant, e há plano Teams/trial (trial "can't publish the agent"). Cotas, Copilot Credits, agent inventory, Agent 365 e a maioria dos controles de governança são de nível organizacional (entra/pago). Analytics Monitor é "available in all geographies".
- **Agent 365** aparece como o "central control plane to observe, govern, and secure Copilot Studio agents" — ou seja, parte da governança saiu do produto e vive na oferta Agent 365 (ver `agent-365.md`).
- **Lacunas**: não achei fonte para "pausar", "retomar", "filas e workers", "tarefa aberta", "caixa de entrada", "livro de mensagens" e "colisão de nomes". O análogo de "configuração por projeto" é o *environment*, e o de "rastro de sessão" é a transcrição (retenção de 28 dias no produto).
- **Siglas expandidas na primeira ocorrência**: MCP (*Model Context Protocol*); A2A (*Agent2Agent*); DLP (*Data Loss Prevention*); RBAC (*Role-Based Access Control*); UI (*User Interface*); DAU/MAU (usuários ativos diários/mensais); CMK (*Customer-Managed Keys*); CCCU (*Copilot Credit Commit Unit*); RPM/RPH (requisições por minuto/hora); YAML (formato de serialização legível por humanos).
