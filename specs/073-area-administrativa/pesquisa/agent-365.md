# Microsoft Agent 365

- **URL**: https://learn.microsoft.com/en-us/microsoft-agent-365/ (documentação oficial); produto: https://www.microsoft.com/microsoft-agent-365
- **Data da visita**: 2026-10-24
- **Como foi pesquisada**: WebFetch na documentação oficial em learn.microsoft.com (nenhum binário local, nenhum login). Páginas: hub da documentação, `overview`, `admin/agent-365-overview`, `admin/agent-registry-overview`, `developer/` (SDK e CLI) e a página de segurança/governança do Copilot Studio que cita o Agent 365.
- **O que foi aberto de verdade**:
  - https://learn.microsoft.com/en-us/microsoft-agent-365/ — hub: "Agent 365 is the control plane for IT and security leaders to observe, secure, and govern agents across the organization"; três pilares (Observe / Govern / Secure).
  - https://learn.microsoft.com/en-us/microsoft-agent-365/overview — "observe, govern, and secure"; *agent registry* centralizado; "**As of May 1, 2026, Microsoft Agent 365 is generally available for the Commercial segment on a per user basis**"; "works best when using Microsoft E5 as a pre-requisite"; licenciado por usuário.
  - https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-365-overview — o workload **Agents** no Microsoft 365 admin center: "Discover and review the agents ... Understand who published and owns each agent ... Control availability and access to each agent"; "**Governance actions** ... Review and approve pending agent requests", "Assign ownership to agents without owners", "Investigate and remediate agents at risk", "Review agents with exceptions"; "approving agent requests or assigning ownership can only be performed by users in the **AI Administrator** or **Global Administrator** roles"; métricas de "Active users", "**Agent run-time**" (horas trabalhadas em 30 dias), "Agents by creators", "Top platforms", "Trending agents"; Agent 365 cobre agentes de Copilot Studio, SharePoint, Agent Builder, Foundry, Agents Toolkit e de plataformas externas.
  - https://learn.microsoft.com/en-us/microsoft-agent-365/admin/agent-registry-overview — **Agent Registry**: visão central de todos os agentes; filtros por "Status, Publisher Type, Channel, Platform, Data source"; ações "Add agent" (upload de manifesto `.zip`), "Manage pinned agents", "Export" (CSV com "Name, Status, Channel, Date created, Last modified, Publisher, ... Owner, Platform, Instructions"); "Agents without owners", "Unmanaged agents", coluna "**Risks**" agregando sinais do Microsoft Purview, Microsoft Entra e Microsoft Defender; upload permite "apply either an existing policy template, a custom policy, or the default policy"; Graph API em preview (`GET /copilot/admin/catalog/packages`).
  - https://learn.microsoft.com/en-us/microsoft-agent-365/developer/ — **Agent 365 SDK e CLI**: o SDK "extend[s] agents built using any agent SDK or platform with identity, notifications, security, and governed access to Microsoft 365 data"; agentes podem "Use Entra-backed Agent Identity", "Receive and respond to notifications from Teams, Outlook, Word comments, and emails", "Gain full observability via Open Telemetry", "Invoke governed Model Context Protocol (MCP) servers", "Function within an IT-approved blueprint system"; CLI cria *agent blueprints*, publica no admin center, deploy no Azure; o *blueprint* é "an IT-approved, pre-configured definition of an agent type" com DLP, restrições de acesso externo e regras de logging.
  - https://learn.microsoft.com/en-us/microsoft-copilot-studio/security-and-governance — confirma que o Agent 365 "serves as a central control plane to observe, govern, and secure Copilot Studio agents"; "Microsoft Entra network controls (via Agent 365) ... This capability is generally available"; eventos de governança do Agent 365 fluem por um plano separado ("aren't covered by the configured Lockbox").

## Observações
- **Disponibilidade/GA**: a documentação afirma "**As of May 1, 2026, Microsoft Agent 365 is generally available for the Commercial segment on a per user basis**" (fonte: `overview`). Pré-requisitos: "works best when using Microsoft E5"; pelo menos um usuário com "qualifying Microsoft Agent 365 license"; também incluído no Microsoft 365 (E7). A nota da tarefa menciona anúncio no Ignite 2025 — **não confirmei essa data de anúncio na documentação aberta**; o que verifiquei foi a data de GA acima.
- **A documentação hoje É razoavelmente completa** (hub, overview, admin/registry, developer/SDK+CLI, e a página de segurança do Copilot Studio). Não é "escassa" como o briefing supunha. Ainda assim, é uma oferta **de nível organizacional e paga** (por usuário), com forte dependência de Microsoft 365/Entra/Purview/Defender.
- **Recorte de escopo**: o Agent 365 é um **plano de controle** (observar/governar/segurar agentes), não uma plataforma para construir agentes. Por isso itens como "pausar/retomar sessão", "chaves e segredos", "filas e workers", "custo" e "caixa de entrada" ficaram vazios: não há fonte porque o conceito não existe nessa camada.
- **Siglas expandidas na primeira ocorrência**: RBAC (*Role-Based Access Control*); MCP (*Model Context Protocol*); A2A (*Agent2Agent*); DLP (*Data Loss Prevention*); SDK (*Software Development Kit*); CLI (*Command-Line Interface*); GA (*General Availability*); IT (*Information Technology*); API (*Application Programming Interface*); CSV (*Comma-Separated Values*); IRM (*Information Rights Management*).
