- **URL**: https://n8n.io/ (documentação: https://docs.n8n.io/)
- **Data da visita**: 2026-10-24
- **Como foi pesquisada**: WebFetch na documentação oficial em docs.n8n.io e no site n8n.io (nenhum login). O binário local **não foi executado**: `docker` não existe nesta máquina e `npx n8n` baixaria um pacote pesado — a tentativa foi deliberadamente dispensada e a pesquisa foi feita só por documentação (registrado abaixo). Também usei a interface de consulta da própria doc (`https://n8n-docs-retrieval.n8n-docs-retrieval.workers.dev/?q=...`), que devolve trechos com o `source_url`.
- **O que foi aberto de verdade**:
  - https://docs.n8n.io/build/understand-workflows/save-and-publish-workflows.md — publicar "makes your workflow live and locks it to a specific version"; edição é salva sozinha em "1 to 5 seconds"; "unpublishing takes it out of production"; estado "**Partial publish**" = um gatilho falhou mas o workflow "keeps running the triggers that did activate"; "**Failed publish**" = "None of the workflow's triggers activated, so the workflow isn't running".
  - https://docs.n8n.io/hosting/scaling/queue-mode/ — **queue mode**: main gera execuções, workers executam; o main manda o execution ID ao Redis, que "maintains the queue of pending executions and allows the next available worker to pick them up"; `EXECUTIONS_MODE=queue`; `--concurrency` default 10; `/healthz`, `/healthz/readiness` e `/metrics` no servidor do worker; webhook processors; multi-main (Enterprise).
  - https://docs.n8n.io/administer/manage-users-and-access/understand-instance-roles.md — papéis de instância **Owner, Admin, Member** + custom roles; Owner "Access the n8n Cloud console"; Admin disponível em "n8n Cloud (Pro, Enterprise) and self-hosted Enterprise"; "no way to see who created a particular workflow".
  - https://docs.n8n.io/administer/manage-users-and-access/set-permissions-and-roles-rbac.md — RBAC em dois níveis (instância e por projeto); custom roles restritas a "Cloud Enterprise and self-hosted Enterprise".
  - https://docs.n8n.io/administer/manage-users-and-access/set-permissions-and-roles-rbac/see-available-roles.md — papéis de instância e de projeto; nó pode ser bloqueado/permitido "for the instance or a project".
  - https://docs.n8n.io/administer/observe-and-log/stream-logs-to-external-systems — **Log Streaming é Enterprise** ("n8n Cloud: Enterprise, Self-hosted: Enterprise"); destinos syslog, webhook genérico e Sentry; grupos de eventos incluem "**Audit**" (login, credenciais, chaves de API, workflows, variáveis, segredos externos, role mapping, pacotes) e "**Queue**" (Job enqueued, dequeued, completed, failed, stalled); escreve num log local antes de encaminhar.
  - https://docs.n8n.io/build/integrate-ai/ai-examples/human-in-the-loop-for-tools — **HITL (*Human-in-the-Loop*)** para chamadas de ferramenta de agentes: um agente pausa e pede aprovação; o revisor "Approve" (roda a ferramenta) ou "Deny" (cancela e informa o agente); canais: Chat, Slack, Discord, Telegram, Microsoft Teams, Gmail, WhatsApp Business Cloud, Google Chat, Microsoft Outlook; funciona também quando um agente é usado como ferramenta por outro ("Sub-agents ... HITL steps inside the sub-agent still function").
  - https://docs.n8n.io/build/understand-workflows/executions.md — "An execution is a single run of a workflow"; modo Manual e Production; lista por workflow e lista geral; filtro; só execuções de produção contam para a cota.
  - https://docs.n8n.io/insights/ — **Insights**: execuções de produção, taxa de falha, run time médio e "time saved"; banner de 7 dias em todos os planos; dashboard limitado a Cloud Pro/Enterprise e self-hosted Business/Enterprise; coleta desde n8n 1.89.0.
  - https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-langchain.mcpclient/ — nó **MCP Client** ("use the tools that are exposed by an external MCP server") e **MCP Server Trigger** ("expose n8n tools to external AI Agents").
  - https://docs.n8n.io/integrations/builtin/cluster-nodes/root-nodes/n8n-nodes-langchain.agent/ — nó **AI Agent**: recebe um chat model + ferramentas; "an autonomous system that receives data, makes rational decisions, and acts ... to achieve specific goals"; pelo menos uma ferramenta é obrigatória.
  - https://docs.n8n.io/deploy/host-n8n/configure-n8n/basic-configuration/use-environment-variables/credentials.md — variáveis de **credential overwrites** (`CREDENTIALS_OVERWRITE_DATA/_FILE`, `_ENDPOINT`, `_PERSISTENCE` — esta "Required for multi-instance or queue mode to propagate overwrites to workers").
  - https://docs.n8n.io/deploy/host-n8n/configure-n8n/basic-configuration/use-environment-variables/external-secrets.md — "use an external secrets store to manage credentials for n8n" (HashiCorp Vault, Infisical); variáveis `N8N_EXTERNAL_SECRETS_UPDATE_INTERVAL` etc.
  - https://n8n.io/enterprise/ — "Full audit trail, tied to identity ... who created, edited, or deleted a workflow and when"; "Custom roles and project-level permissions"; "Secret manager integration (Vault, AWS, Azure, GCP, 1Password, Infisical)"; "Audit events, logs, and metrics can be streamed to Splunk, Datadog, Grafana, or an OpenTelemetry endpoint".
  - https://n8n.io/pricing/ — planos **Starter** (2.5K execuções), **Pro** (10K), **Business** (40K, self-hosted), **Enterprise** (custom, "200+ concurrent executions"); "unlimited users & workflows and every integration"; cobrança "based on monthly workflow executions".

## Observações
- **Binário local**: não executado. `docker` não existe nesta máquina; `npx n8n` (node v24 existe) baixaria um pacote pesado, então a tentativa foi dispensada de propósito e a pesquisa ficou só na documentação. Nada foi instalado nem rodado.
- **Versão livre vs. paga**: a Community Edition é gratuita e self-hosted; o Cloud trial dá "Pro-level features" com limites. **Enterprise-only**: log streaming (audit events), execution data redaction, external secret store, multi-main, custom roles (instância e projeto). **Business** (self-hosted): SSO/LDAP, múltiplos ambientes, queue mode, "Version control using Git". Papéis de projeto existem em "n8n Cloud, every plan; self-hosted on Registered Community, Business, and Enterprise".
- **Lacunas**: não achei fonte para "cadastro de agentes", "lista de agentes vivos", "caixa de entrada", "livro de mensagens" nem "colisão de nomes" — o n8n não modela "agentes" como entidades administrativas (são nós em workflows). A2A não aparece na doc; só MCP. A chave de criptografia de credenciais não apareceu nas páginas abertas (foi citada apenas via *credential overwrites* e segredos externos).
- **Siglas expandidas na primeira ocorrência**: RBAC (*Role-Based Access Control*); MCP (*Model Context Protocol*); A2A (*Agent2Agent*); HITL (*Human-in-the-Loop*); SSO (*Single Sign-On*); LDAP (*Lightweight Directory Access Protocol*); UI (*User Interface*); CI (*Continuous Integration*).
