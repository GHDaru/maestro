Como ler este wireframe. Arquivo HTML estático: sem servidor, sem JavaScript de dados; CSS mínimo, em cinza. Nenhum número é inventado — o valor ilustrativo vem marcado exemplo e o valor vivo aparece como — com o motivo ao lado.

Fitness functions de UX (ciclo 066). Valem F1 (todo número/selo com data-fonte), F7 (idade nunca digitada), F8 (todo "—" com motivo) e F9 (nenhum controle só-ícone sem aria-label); F2–F6 e F10–F12 são n/a — supõem servidor e API, que este protótipo não tem. Declarado, não omitido.
