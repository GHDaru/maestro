livro de mensagens

Contexto Mensageria — o registro append-only unificado das mensagens entre sessões. Fonte real do registro hoje: a fila outbox (SQLite, painel/fila_outbox.py) — o livro é a leitura unificada dela. Não é o livro de ponto (Task ledger, docs/records/tarefas.jsonl): mesmo nome, outro objeto (mapa §7).

Regra do livro: nunca se apaga uma linha — corrigir é acrescentar. A leitura é marcada, não removida.

Ordem do livro: da mais antiga à mais nova — a ordem de registro acompanha a hora. Rodada 4, decisão 7 (ordem 8 a 12): a lista passa a respeitar o próprio título.

Destinatário pretendido × real. O livro guarda os dois: quando diferem, a linha fica marcada — é a prova de entrega errada, antes só visível à mão.

Quem pode ver o livro: a leitura é restrita ao projeto — só as sessões do mesmo 410_MAESTRO leem as linhas do projeto, coerente com o default-deny. Rodada 4, decisão 7 (a restrição ao projeto é declarada, não inferida). Ler o livro de outra sessão do mesmo projeto exige a ref dela e não altera nada — o livro é append-only.

Quem pode escrever: só a sessão dona da mensagem acrescenta a própria linha. Nem o regente reescreve uma linha — corrigir é acrescentar.
