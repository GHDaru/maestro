Antes de tudo: a raia

ambiguidade × raio × irreversibilidade decide quanto processo a mudança recebe. Leve: o pull request é o artefato (pula spec/plan/tasks). Plena: o fluxo inteiro. Infra: plena + backup, dry-run e rollback.

Por que o fluxo para nos losangos

Gate não mede a qualidade do raciocínio do agente — localiza a responsabilidade. Os quatro amarelos são indelegáveis; o verde (DoD) é mecânico e bloqueia sozinho.

O ramo de interface

Feature com tela abre um ramo: papel semântico antes do componente, gate de UX, e jornada viva — captura gerada do build real + heurística datada. Heurística mais velha que a captura = documentação vencida.

O método sai do repositório

Três camadas, do completo ao leve: A script (tudo) · B plugin do Claude Code · C npx skills add (75+ agentes). Cada uma diz o que não leva — instalar um quinto do método não é instalar o método.

O laço que fecha

A retrospectiva devolve ao início: erro recorrente vira regra versionada (princípio, skill ou script). O processo aprende — e cada volta o deixa mais barato.

Maestro · o humano decide a política e os pontos irreversíveis; a máquina executa e prova. Reversibilidade compra velocidade.
